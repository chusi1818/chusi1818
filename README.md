## Free tools & open data

Most cross-reference tables online ignore one thing: the same cartridge is sold under
different part numbers in different regions. `HP 80A` and `CF280A` are physically the
same cartridge. `HP 59A` and `CF259A` are the same cartridge. Fitting the wrong regional
variant is the usual cause of *"toner not recognised"* and *"supply error"* messages —
and it is invisible in every lookup table that lists only one part number.

### Toner cross-reference & chip checker

Enter a printer model → every compatible cartridge, with OEM code, colour, **region
variant**, declared page yield and **whether a chip is fitted**.
Enter an OEM code → every printer it fits.

**→ [chusiprint.com/tools/toner-cross-reference](https://chusiprint.com/tools/toner-cross-reference)**

No sign-up, no email gate.
